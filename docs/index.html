Database Design

Structured schema with proper constraints, indexing, and relationships

articles
Core pubmed articles with full-text search capability
  • PK pmid INTEGER
  • title TEXT
  • abstract TEXT
  • pub_date DATE
  • doi VARCHAR(255)
  • FK journal_issn VARCHAR(9)
authors
Author information with institutional affiliation
  • PK id SERIAL
  • name VARCHAR(255) UNIQUE
  • affiliation TEXT
  • orcid VARCHAR(19)
journals
Journal metadata with impact factor tracking
  • PK issn VARCHAR(9)
  • name VARCHAR(500) UNIQUE
  • impact_factor NUMERIC
  • publisher VARCHAR(255)
article_authors
Many-to-many relationship between articles and authors
  • PK FK article_id INTEGER
  • PK FK author_id INTEGER
  • author_order SMALLINT
  • is_corresponding BOOLEAN
article_citations
Citation graph with recursive query support
  • PK citing_article INTEGER FK
  • PK cited_article INTEGER FK
  • created_at TIMESTAMP

Key Features

Comprehensive functionality from data import to interactive search

📦

GoodLoader Batch Import

Custom Java data loader with truncate-and-refresh, schema isolation, and bulk insertion. Processes millions of articles from NDJSON to PostgreSQL in minutes.

🔍

Full-Text Search

PostgreSQL tsvector-powered search with ranking, highlighting, and real-time suggestions. Supports advanced boolean queries and phrase matching.

🔗

Citation Graph

Recursive CTE queries traversing citation chains. Discover related articles, track research influence, and navigate the citation network.

📊

Layered Architecture

Clean separation: Controller → Service → Repository. Each layer has a single responsibility, making the codebase maintainable and testable.

🎨

Vue 3 Responsive UI

Modern single-page application with Composition API, real-time filters, pagination, and mobile-responsive design. Built with Vite for fast HMR.

🔐

User Management

PL/pgSQL scripts for creating roles with granular permissions. Supports schema-level isolation for multi-tenant deployments and grading environments.

Backend Code Sample

Repository layer with JDBC-based data access

📄 ArticleRepository.java Spring Boot · JDBC
@Repository public class ArticleRepository { private final JdbcTemplate jdbcTemplate; public ArticleRepository(JdbcTemplate jdbcTemplate) { this.jdbcTemplate = jdbcTemplate; } public List<Article> searchByKeyword( String keyword, int page, int size) { String sql = """ SELECT a.*, j.name AS journal_name, ts_rank(to_tsvector('english', a.title || ' ' || a.abstract), plainto_tsquery('english', ?)) AS rank FROM articles a LEFT JOIN journals j ON a.journal_issn = j.issn WHERE to_tsvector('english', a.title || ' ' || a.abstract) @@ plainto_tsquery('english', ?) ORDER BY rank DESC LIMIT ? OFFSET ? """; return jdbcTemplate.query(sql, new ArticleRowMapper(), keyword, keyword, size, (page - 1) * size); } }
